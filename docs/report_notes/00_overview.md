## 3. ผลลัพธ์รวม (สำหรับบทที่ 4)

ตัวเลขล่าสุดดูได้จากคำสั่ง `py -3.13 -m pipeline.run_all` หรือหน้าแรกของเว็บ
- **คุณภาพข้อมูล:** 92.6% → 97.4% (Uniqueness, Consistency, Accuracy = 100%)
- **ความแม่นเทียบกับเฉลย:** ตัดแถวถูก 130/130, แก้/เติมค่าถูก 100%
- **ETL:** Load verification ผ่านทุกข้อ, Incremental loading รันซ้ำได้โดยไม่เกิดข้อมูลซ้ำ
- **Recommendation:** ทายอันดับ 1 ถูก 51.9% เทียบกับ Baseline 12.4%
- **Forecast:** ชนะ Baseline 2 จาก 3 เดือน, พลาดเดือน มิ.ย. เพราะ มช. เปิดเทอม
- **Insight ทางธุรกิจ:** วันหยุดนิมมาน / ท่าแพขายดีขึ้น แต่ มช. ลดลง → ควรวางแผนแยกสาขา / เมนูคู่ที่ควรจัดโปรโมชัน 4 คู่
