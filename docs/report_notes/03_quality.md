### มิติ Timeliness (สูตรจาก Ch3)
```
Timeliness = max(0, 1 − Currency / Volatility)
Currency   = วันที่รับข้อมูล (1 ก.ค. 2569 จากเวลา export ในไฟล์ท่าแพ) − วันที่ของข้อมูลล่าสุด (30 มิ.ย.) = 1 วัน
Volatility = 7 วัน (สมมุติว่าเจ้าของร้านดูรายงานรายสัปดาห์)
Timeliness = 1 − 1/7 = 85.71%
```
ตีความ: ข้อมูลช้าไป 1 วันจากรอบรายงาน 7 วัน **ต่ำกว่าเป้าแต่ไม่ใช่ปัญหาที่ต้องทำความสะอาด** เป็นเรื่องของรอบการส่งข้อมูล ถ้าอยากให้ดีขึ้นต้องส่งข้อมูลทุกวัน
